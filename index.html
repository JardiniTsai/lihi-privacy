本隱私權政策說明利害短網址有限公司（以下稱「本公司」、「lihi」或「我們」）在您使用 lihi.io、app.lihi.io、knowledge.lihi.io、lihi 短網址服務、QR Code、品牌網域、點擊統計、行銷連結管理及其他相關服務時，如何蒐集、使用、保存、保護與處理您的資料。

當您瀏覽或使用 lihi 相關網站與服務，即表示您已閱讀並了解本隱私權政策。若您不同意本政策內容，請停止使用本公司所提供之服務。

1. 適用範圍

本隱私權政策適用於本公司營運之網站、應用程式、後台系統、知識庫、客服管道與相關服務，包括但不限於：

  • lihi.io
  • app.lihi.io
  • knowledge.lihi.io
  • lihi 短網址服務
  • lihi QR Code 與短連結管理功能
  • 自訂網域、品牌網域與相關設定功能
  • 點擊統計、參數追蹤、A/B 分流與行銷分析功能
  • 客服、表單、通知與其他支援服務
  • 內部品牌監測後台（僅限授權內部人員登入使用）

第三方網站、第三方服務或由第三方提供之內容，應適用其各自的隱私權政策，本公司不負責第三方網站或服務之資料處理方式。

2. 我們蒐集的資料

依照您使用服務的方式不同，我們可能會蒐集或處理以下類型的資料。

2.1 帳號與會員資料

當您註冊、登入或使用 lihi 帳號時，我們可能會蒐集：

  • 姓名或顯示名稱
  • Email 信箱
  • 登入方式
  • 帳號設定
  • 會員方案與訂閱狀態
  • 與帳號管理相關之必要資訊

2.2 服務使用資料

當您建立、管理或使用 lihi 服務時，我們可能會處理：

  • 您建立的短網址
  • 原始目標網址
  • 自訂網域或品牌網域設定
  • QR Code 相關資料
  • UTM、參數、標籤或活動設定
  • A/B 分流或導流設定
  • 連結狀態、導向設定與服務操作紀錄

2.3 點擊統計與技術資料

當使用者點擊短網址、掃描 QR Code 或與 lihi 管理之連結互動時，我們可能會處理技術與統計資料，例如：

  • 點擊時間
  • 來源網址或 referrer 資訊
  • 瀏覽器類型
  • 裝置類型
  • 作業系統
  • IP 位址
  • 約略地理位置
  • User Agent
  • 連結導向狀態與錯誤紀錄

上述資料主要用於提供點擊統計、流量分析、資安防護、濫用防範、服務維護與功能改善。

2.4 付款與訂閱資料

若您使用付費方案、加購服務或購買相關產品，我們可能會處理與付款、訂閱、發票或交易紀錄相關之資料。

實際付款資訊可能由第三方金流服務提供者處理。本公司不會任意公開您的付款資料，並會依服務營運與法令需求保存必要之交易紀錄。

2.5 客服與聯絡資料

當您透過客服頁面、表單、Email 或其他管道聯繫我們時，我們可能會蒐集：

  • 您的姓名或稱呼
  • Email 或其他聯絡資訊
  • 詢問內容
  • 附件、截圖或您主動提供的資料
  • 客服處理紀錄

3. 我們如何使用資料

我們可能基於以下目的使用資料：

  • 提供、維護與改善 lihi 服務
  • 建立、管理與保護使用者帳號
  • 建立與管理短網址、QR Code、自訂網域及相關功能
  • 提供點擊統計、流量分析、A/B 分流與行銷追蹤功能
  • 處理訂閱、付款、發票、方案異動與客服需求
  • 發送服務通知、重要公告或必要之帳務資訊
  • 偵測、預防與處理詐欺、濫用、釣魚、惡意程式、垃圾訊息或其他違法行為
  • 維護服務安全、穩定性與系統效能
  • 遵守法令、主管機關、司法機關或其他合法要求
  • 執行本公司服務條款與相關政策

4. Cookies 與類似技術

我們可能使用 Cookies 或類似技術，以維持網站與服務正常運作、記住使用者偏好、改善使用體驗、進行流量分析、強化資安防護及提供必要功能。

您可以透過瀏覽器設定管理或停用 Cookies，但若停用 Cookies，部分網站或服務功能可能無法正常運作。

5. 第三方服務

為提供、維護與改善服務，我們可能會使用第三方服務提供者協助處理部分資料，例如：

  • 網站主機與雲端基礎設施
  • 金流與付款處理服務
  • Email、通知與客服系統
  • 網站分析與流量統計工具
  • 資安防護、錯誤追蹤與系統監控工具
  • 網域註冊、DNS 或相關技術服務

上述第三方服務提供者僅得於提供服務所需範圍內處理資料，並應依其隱私權政策與適用法令處理相關資料。

6. 資料分享與揭露

我們不會出售您的個人資料。

在以下情況下，我們可能會分享或揭露必要資料：

  • 提供服務所需，與合作之服務提供者共享必要資料
  • 依法令、主管機關、司法機關或合法程序要求提供
  • 為保護本公司、使用者或第三方之權利、財產、安全或合法利益
  • 為偵測、預防或處理詐欺、濫用、資安風險或違法行為
  • 因公司合併、收購、資產轉讓、重組或其他商業交易需要
  • 經您同意或依您指示提供

7. 資料保存

我們會於提供服務、履行契約、處理帳務、維護安全、改善服務、解決爭議、遵守法令或執行權利所需期間內保存資料。

不同類型資料的保存期間可能因服務內容、帳號狀態、法令要求、稅務或會計需求、資安與營運需求而有所不同。

8. 資料安全

我們會採取合理之技術與組織安全措施，保護資料免於未經授權之存取、使用、修改、揭露、遺失或破壞。

然而，任何網際網路傳輸或電子儲存方式皆無法保證百分之百安全。您應妥善保管帳號、密碼、登入方式及其他驗證資訊，避免帳號遭他人未授權使用。

9. 使用者權利

依照您所在地區之適用法令，您可能有權要求查詢、閱覽、複製、更正、補充、停止蒐集、停止處理、停止利用或刪除與您相關之個人資料。

若您欲行使相關權利，請透過本政策下方之聯絡方式與我們聯繫。我們可能需要驗證您的身分後，才能處理您的請求。

10. 未成年人

若您為未成年人，應在父母或法定監護人閱讀、了解並同意本隱私權政策與相關服務條款後，方得使用 lihi 服務。

若父母或法定監護人認為未成年人未經同意提供個人資料，可聯繫我們協助處理。

11. 跨境資料處理

因服務營運、雲端基礎設施或第三方服務提供者所在地不同，您的資料可能會被傳輸、儲存或處理於您所在國家或地區以外之地點。

我們會依適用法令與合理安全措施處理跨境資料傳輸與保存。

12. 外部連結與嵌入內容

lihi 網站、知識庫或服務內容可能包含第三方網站連結、嵌入內容、工具或資源。當您點擊外部連結或與第三方內容互動時，該第三方可能依其隱私權政策蒐集或處理資料。

本公司不負責第三方網站、服務或內容之資料處理方式，建議您自行查閱其隱私權政策。

13. 本政策之更新

我們可能會不定期更新本隱私權政策，以反映服務內容、營運方式、技術工具或法令要求之變更。

本政策更新時，頁面上方之「最後更新日期」將同步調整。您於政策更新後繼續使用 lihi 服務，即表示您已閱讀並了解更新後之內容。

14. 品牌監測與 Threads 公開貼文

本公司另營運一套僅供授權內部人員登入使用的品牌監測後台，用以瞭解公眾在 Threads 上對本公司自有品牌的公開討論。該後台不對一般使用者開放，亦不是 lihi 短網址產品的一部分。

14.1 用途

我們會透過 Meta 官方 Threads API（使用 threads_basic 與 threads_keyword_search 權限）搜尋提到本公司自有品牌的公開 Threads 貼文，供內部人員辨識潛在客戶與客戶申訴，並據以改善服務與處理客訴。搜尋關鍵字以本公司品牌與產品名稱為主，包括「lihi」、「lihi.io」、「lihi 短網址」及「貝克菜」；內部人員亦可能啟用少數相關之需求詞或競品詞，仍僅用於上述內部監測目的。

14.2 我們蒐集的資料與來源

資料來源為 Meta 官方 Threads Keyword Search API 所回傳、且已由作者自行公開於 Threads 的貼文；我們不會以此方式讀取私人帳號中未公開的內容，也不會蒐集私訊。

針對符合關鍵字的公開貼文，我們可能保存以下欄位：

  • 貼文網址
  • 平台貼文識別碼
  • 作者公開顯示名稱
  • 作者公開帳號名稱
  • 公開內文（及系統產生或平台提供之標題，如有）
  • 發文時間
  • 抓取時間
  • 符合的搜尋關鍵字
  • 內部 AI 分類結果與理由（例如：潛在客戶、客訴或一般討論）

目前我們使用的 Threads 關鍵字搜尋不提供作者帳號 ID，因此該欄位會存為空值，我們不會保存作者帳號 ID。這與第 14.7 節的說明一致。

我們不會向 Threads 要求貼文「擁有者」等非該搜尋端點提供的欄位，也不會另外蒐集您的 Email、電話號碼或非公開的個人檔案資料。

14.3 法律依據與特定目的

本公司為台灣公司，就本節資料之蒐集、處理與利用，適用中華民國《個人資料保護法》及相關法規。

特定目的為：維護自身品牌商譽、辨識潛在客戶、處理客戶申訴，以及改善本公司服務。所處理者主要為當事人自行公開於 Threads、或其他已合法公開之個人資料。我們僅在上述特定目的之必要範圍內處理這些資料。

14.4 我們不會做的事

就本節所述之 Threads 資料，我們不會：

  • 透過本應用程式在 Threads 發文、回覆、引用、轉發或傳送私訊
  • 出售這些資料，或將這些資料提供給第三方供其自行行銷或再利用（本政策第 6 節所列依法令、司法或安全等必要情形除外）
  • 將這些資料用於投放個人化廣告，或建立供對外使用的個人檔案
  • 在公開網站、外掛或對客戶開放的搜尋功能中展示這些資料

品牌監測後台僅限授權內部人員存取。

14.5 保存期限

符合關鍵字而保存的 Threads 公開貼文及其分類資料，會保存至本內部品牌監測服務停止使用為止。系統不會在固定期限屆滿後自動刪除這些貼文。

若使用者或貼文作者寄信至 service@lihi.io 提出刪除請求，我們會以人工方式查找並刪除相關資料。

若我們收到 Meta 或 Threads 的解除授權回呼，或資料刪除回呼，我們會依現行程式處理，詳見第 14.7 節。

僅在我們收到 Meta 資料刪除回呼時，系統會另外建立一筆申請紀錄與確認碼，供您查詢辦理進度。該紀錄含確認碼、使用者 ID 的雜湊值（不是明文帳號 ID）、狀態、刪除筆數，以及申請與完成時間，不含已刪除的貼文內容，並自申請時起保存 12 個月，期限屆滿由系統刪除。解除授權回呼不會建立此類申請紀錄。

14.6 資料安全與存取限制

我們會採取合理之技術與組織安全措施，保護本節資料免於未經授權之存取、使用、修改、揭露、遺失或破壞。品牌監測後台設有存取管制，僅授權內部人員可以登入。用以呼叫 Threads API 的授權憑證僅保存在受控的伺服器環境，不會公開於網站或對一般使用者顯示。

因服務營運與雲端基礎設施所在地不同，資料可能依本政策第 11 節於台灣以外之地點傳輸、儲存或處理。

14.7 查詢、刪除與相關權利之行使

依照《個人資料保護法》，您就與您相關之個人資料，得請求查詢、閱覽、複製、更正、補充、停止蒐集、停止處理、停止利用或刪除。我們可能需要先驗證您的身分或請求所涉之貼文，才能處理。

您可以透過以下方式提出申請：

  1. 官方客服管道（人工申請）
    請透過本政策「聯絡我們」一節所載之官方客服管道提出，也就是「聯絡 lihi 客服」（https://lihistatus.com/contact），或寄信至 service@lihi.io。請在主旨或內容註明「Threads 資料刪除／查詢申請」，並盡量提供您的 Threads 公開帳號名稱，以及相關公開貼文網址，以便我們查找紀錄。
  2. Meta 資料刪除回呼
    若您透過 Meta 或 Threads 的應用程式設定提出資料刪除請求，Meta 會向我們的資料刪除回呼網址傳送經過驗證的請求：
    https://lihi-brand-monitor.monster7405.workers.dev/threads/data-deletion
    現行程式會驗證請求後，刪除已保存、且作者帳號 ID 與該請求所涉帳號相符的 Threads 貼文。目前 Threads 關鍵字搜尋不提供作者帳號 ID，該欄位會存為空值（見第 14.2 節），因此此回呼通常無法自動對應並刪除這些貼文。系統仍會建立一筆申請紀錄與確認碼，供您查詢辦理進度：
    https://lihi-brand-monitor.monster7405.workers.dev/threads/deletion-status
    申請紀錄的保存方式見第 14.5 節。若您希望我們刪除相關貼文，請依前述第 1 種方式，寄信至 service@lihi.io 並附上相關公開貼文網址，我們將以人工方式查找並刪除。

若員工或其他已授權本應用程式的 Threads 使用者在 Meta 或 Threads 設定中移除本應用程式，Meta 會向我們的解除授權回呼網址傳送經過驗證的請求：
https://lihi-brand-monitor.monster7405.workers.dev/threads/deauthorize
現行程式同樣會刪除已保存、且作者帳號 ID 與該帳號相符的 Threads 貼文。基於第 14.2 節所述原因，此回呼通常也無法自動對應並刪除關鍵字搜尋所保存的貼文。解除授權回呼不會建立申請紀錄或確認碼。

我們將於收到有效且資料齊備的請求後 15 日內完成處理；必要時得延長 15 日，並於延長時通知申請人。若請求不完整或尚須驗證身分，處理期間自補齊資料之次日起算。
